# Harlo Agent-Ops Bases — Lite v1.1.1

A free, ready-to-build Airtable base for a **Client CRM + Deal Pipeline**, with an agent recipe pack for driving it from an MCP-capable AI agent.

## What's inside

- `bases/a-client-crm-deal-pipeline/SCHEMA.md` covers the tables, fields, views, linked records and formulas.
- `bases/a-client-crm-deal-pipeline/data/*.csv` holds original, fictional seed data.
- `bases/a-client-crm-deal-pipeline/AUTOMATIONS.md` describes each Airtable automation step by step.
- `bases/a-client-crm-deal-pipeline/AGENT-RECIPES.md` has prompts for a daily briefing, data hygiene and a pipeline review.
- `bases/a-client-crm-deal-pipeline/SETUP.md` and `SETUP.pdf` are the setup guide.

Start with `SETUP.md` or `SETUP.pdf`.
